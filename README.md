# FrendGame

Если на GitHub Pages показывается старая версия или 404, используй этот режим деплоя:

1. Открой **Settings → Pages**.
2. В поле **Build and deployment** выбери **Source: GitHub Actions**.
3. Убедись, что пуш идёт в `main` (или `master`) — workflow `Deploy static site to GitHub Pages` автоматически выкатит последнюю версию.

## Почему это исправляет проблему

При деплое через ветку (`gh-pages`/`docs`) иногда остаётся старый артефакт или старый source. Workflow деплоит именно текущий коммит из репозитория и убирает рассинхрон старой версии.
